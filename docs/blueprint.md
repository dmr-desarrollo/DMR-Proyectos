# **App Name**: Proyectum

## Core Features:

- Project Details Entry: Input client details, project subject, start/end dates, estimated budget, progress stage, and account manager.
- Project Tracking Dashboard: View projects in a list or Kanban board to monitor status. With filtering by client, date, or stage.
- Activity Logging: Log every interaction/milestone related to the project with timestamps. Display logs chronologically within each project.
- Activity Planner: Schedule tasks, set deadlines, and assign tasks related to each project. Display activities on a timeline.
- AI Project Summarizer: Generate summaries from project logs highlighting critical achievements or roadblocks.
- AI Guidance Tool: Use AI as a tool to provide suggestions for next actions. Analyze historical successful projects with similar attributes and stages to offer insights.

## Style Guidelines:

- Primary color: Slate blue (#778DA9) for a professional, reliable feel.
- Background color: Light gray (#E0E1DD) to provide a neutral, clean backdrop.
- Accent color: Mustard gold (#FFC857) for highlighting actions and key info.
- Headline font: 'Space Grotesk', a sans-serif for a modern, professional aesthetic.
- Body font: 'Inter', a sans-serif for clarity and readability in detailed information.
- Use a consistent set of outline icons to represent project statuses, tasks, and filters.
- Prioritize a clear layout, making heavy use of cards and tables to keep the data clear. Use tabs or segmented views to compartmentalize major functional areas, to improve ease of navigation.
